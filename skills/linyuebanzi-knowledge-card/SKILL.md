# 学科知识卡片生成

## 生图方式

**直接使用当前平台自带的生图能力**，不调用任何外部脚本或第三方 API，也不需要用户配置 API Key。

- 在豆包工作中：使用豆包工作内置的图片生成能力出图
- 在其他 Agent 平台中：使用该平台内置的图片生成工具
- 调用参数：完整提示词（Step 4 产出）、比例 9:16、每次生成 1 张
- 平台不支持 9:16 时，改用最接近的竖版比例（如 3:4），并告诉用户实际用的比例

> 当前平台没有内置生图能力时，不要调用外部脚本或第三方 API，直接告诉用户：这个 Skill 需要在豆包工作这类自带生图的平台里使用；如果用的是 Claude Code 等环境，请改用 `linyuebanzi-edu-infographic`（外部 API 生图版）。

生图会消耗平台额度。单张直接出；批量前先告诉用户一共要出几张（见 Step 9）。

## 工作流程

### Step 1：解析用户输入

用户输入示例：
- `"声现象"` → 自动推断：初二物理 · 第二章
- `"初二物理 光现象"` → 直接提取：初二物理 · 第四章
- `"帮我做一张关于杠杆原理的知识卡片"` → 推断：初二物理 · 简单机械
- `"勾股定理"` → 推断：初二数学
- `"光合作用"` → 推断：初一生物

提取字段：
- `topic`：知识点名称
- `subject`：学科
- `grade`：年级（未提供则自动推断）
- `edition`：教材版本（默认人教版；不同版本章节编排不同，用户指定了版本就按用户的）
- `chapter`：章节号（未提供则按 `edition` 推断；不确定时宁可省略章节号，也不要标一个错的印在图上）
- `key_concepts`：3-5 个核心子概念（自动拆解）
- `focus`：用户额外指定的重点（如"侧重实验""加一道易错点"），没有就留空

### Step 2：拆解子概念

1. 先查 `references/illustration_guide.md`，命中的知识点直接用库里的子概念、插图描述、"必须包含"和"常见错误"
2. 未命中时，按教材拆出 3-5 个子概念，并**现场补出**每个子概念的"必须包含"和"常见错误"（参照 `references/accuracy_checklist.md` 对应学科推导）
3. 每个子概念准备：标题、1-2 句说明、插图描述、公式或关键关系（如有）

### Step 3：出提纲，等用户确认

生图前先把提纲发给用户，**用户确认后再出图**。老师最清楚自己要讲什么，这一步也能避免出错图浪费额度。

提纲格式：

```
【声现象】初二物理 · 第二章（人教版）· 色卡：陶土橙

1. 声音的产生：声音由物体振动产生，振动停止，发声停止
   插图：三个音叉，中间一个带振动箭头，右侧声波弧线
2. 声音的传播：传播需要介质，真空不能传声
   插图：敲鼓，同心圆声波扩散
3. ……

底部：学习提示框「音调看疏密，响度看高低」

确认就回复「出图」；要改直接说，比如「第 3 点加一个回声的例子」。
```

- 用户回复修改意见 → 改提纲后再确认一次
- 用户一开始就说「直接出」「不用确认」→ 跳过这一步
- 批量时一次性列出所有章节的提纲，用户一次确认

### Step 4：确定主题色并构建提示词

**主题色**：全线走低饱和（莫兰迪）色调——不给生图模型"蓝色系"这种粗粒度色名（它会默认输出高饱和的
"AI 信息图蓝"），而是给**具体色卡**：主色 + 底色 + 中性色各带 hex 锚点。同学科不同章节在
可选色卡里轮换主色，同一批次不重复。

| 色卡 | 主色 (accent) | 底色 (bg tint) | 中性 (neutral) | 适用 |
|------|--------------|---------------|---------------|------|
| 陶土橙 | terracotta `#C97E4E` | cream `#F7F1E6` | slate blue-grey `#3A506B` | 物理(声/热)、化学(有机) |
| 深灰蓝 | slate blue `#3A506B` | misty blue-white `#EDF3F8` | warm grey `#8A7D6B` | 物理(电/力)、英语 |
| 柔青绿 | muted teal `#4A9E9B` | pale green-white `#EAF1E3` | grey olive `#8E9678` | 物理(光/透镜)、化学 |
| 雾紫 | misty purple `#7A6296` | ivory `#F7F3ED` | grey blue `#6B7889` | 数学 |
| 深茶绿 | deep tea green `#5F6B4F` | pale green-white `#EAF1E3` | light khaki `#D9C9A3` | 生物 |
| 焦糖棕 | caramel brown `#8A624A` | cream beige `#F4E6C8` | grey coffee `#6F5F4A` | 语文、历史 |
| 鼠尾草绿 | sage green `#8FA08A` | oat `#F2EAD9` | grey olive `#8E9678` | 生物(植物)、英语 |

色彩规则：
- 主色只用在**标题、编号徽章、关键词、公式高亮**上（约 10% 画面），卡片底和背景走底色的浅变体
- 中性色给次级文字、结构线、说明性标注
- 禁止高饱和糖果色、霓虹色、纯 `#FF` 系色相

**构建提示词**：读取 `references/prompt_template.md` 获取提示词骨架，填入以下变量：

- `{topic}` → 知识点名称
- `{grade}` → 年级
- `{subject}` → 学科
- `{chapter}` → 章节（不确定就整段省略）
- `{theme_color}` → 主色（英文名 + hex，如 `misty purple #7A6296`）
- `{bg_tint}` → 底色（英文名 + hex）
- `{neutral_color}` → 中性色（英文名 + hex）
- `{num_sections}` → 子概念数量
- `{sections_content}` → Step 3 确认过的各子概念标题、插图描述、说明文字；"常见错误"列写成提示词里的禁止项

### Step 5：学科准确性自检（提示词层）

在调用生图之前，对构建好的提示词做检查。这是第一道防线，挡"提示词本身写错"。

**数据源：** 同时读取以下三个文件，与当前提示词交叉比对：
- `references/accuracy_checklist.md`：通用检查清单 + 分学科检查清单
- `references/illustration_guide.md`：各知识点的"必须包含"和"常见错误"列，逐项核对
- `references/errata.md`：历史勘误记录，确认没有重复踩坑

**检查顺序：**
1. **通用检查**（所有学科）：错别字、公式变量标注、年级匹配（超纲检查）、章节号与教材版本一致、数值合理性
2. **分学科检查**：按 accuracy_checklist.md 中对应学科的清单逐项过。物理查控制变量条件/电路规范/标量矢量，数学查定理适用条件/图形标注一致，化学查配平/反应条件/↑↓符号，生物查过程四要素/箭头方向，语文查名句原文/作者朝代对应，历史查年代/人物事件对应，英语查拼写/词性/例句语法

如果发现问题，先修正提示词再调用生图。

### Step 6：用平台自带生图能力出图

按上文「生图方式」调用当前平台的内置生图：

- 提示词：Step 4 构建、Step 5 自检后的完整提示词，**原样传入，不要自行删减**
- 比例：9:16 竖版
- 数量：1 张
- 文件名：`{topic}_信息图`，批量时加序号，如 `01_机械运动_信息图`

生成后把图片保存下来并展示给用户；用户指定了保存位置（如某个文件夹）就存到那里。

### Step 7：成图视觉复核（图像层）

这是第二道防线，挡"提示词对但图画错"——生图模型可能渲染出乱码、错别字、公式上下标错乱、箭头画反、电路画混。**每张图生成后必须复核，不复核不交付。**

1. 查看刚生成的图片（直接看图，或用读图工具打开图片文件）
2. 对照 `references/accuracy_checklist.md` 底部"成图视觉复核要点"，逐项核对图中**实际渲染出来**的内容：
   - 所有中文文字：无乱码、无错别字、无缺笔画的伪汉字、无重复字
   - 公式/方程式/数字：与提示词完全一致，上下标正确，单位没丢
   - 图示逻辑：箭头方向、标注位置、结构关系与提示词描述一致
   - 再按该学科的分学科清单过一遍图中内容
3. 判定与处理：
   - **通过** → 交付
   - **不通过** → 在提示词中针对出错点追加强调指令（如 `The formula must read exactly "a² + b² = c²" with correct superscripts`），重新生成。最多重试 2 次
   - 重试 2 次仍不通过 → 交付其中最好的一张，但**必须明确告知用户图中哪里有错**，绝不静默交付错图给学生
4. 交付时附一句复核结果，如「已核对：文字、公式、图示均无误」或「第 2 块的箭头方向有误，建议手动修正」

### Step 8：用户一句话修改

交付后用户可能会说「第 3 块的插图换成 xx」「标题改成 xx」「这里写错了，应该是 xx」：

1. 只改提示词里对应的部分，其他内容保持不变
2. 修改后的内容同样要过 Step 5 自检，再重新生成，并走 Step 7 复核
3. **勘误回流**：用户指出的知识性错误，或复核中发现的知识性错误（不含纯渲染乱码），按格式追加到 `references/errata.md`（当前环境允许写入 Skill 目录时），让下次生成自动避坑；不能写入时，在回复里把勘误条目列出来，方便用户自己补

### Step 9：批量生成

用户请求多个知识点时（如"初二物理上学期全部章节"）：

1. 拆解为独立知识点列表，告诉用户一共要出几张
2. 走 Step 3，一次性列出所有章节的提纲给用户确认
3. **先出第一张作为样卡**，用户确认风格满意后再继续出剩下的；用户说「全部直接出」就不停
4. 为每张图分配不同主题色（同一批次不重复），风格统一但色彩各异
5. **每张图独立走完 Step 5 自检和 Step 7 视觉复核**，不因批量而跳过
6. 最后汇总：逐张报告复核结果（通过 / 重试后通过 / 带瑕疵交付及具体问题）

## 使用示例

```
# 单个知识点
声现象，做张信息图
帮我做一张物态变化的知识卡片

# 指定学科、年级、教材版本
初二物理 光现象（沪科版）

# 跨学科
勾股定理
光合作用

# 批量
帮我把初二物理上学期的知识点全部做成信息图
初二物理 声现象、物态变化、光现象、透镜，分别做一张
```

## 注意事项

- 所有文字必须为中文（英语学科的例句、单词除外）
- 插图以简洁图解为主，不使用真实照片
- 每张信息图的子概念控制在 3-5 个
- 公式必须清晰标注变量含义
- 底部总结区域三选一：关键术语徽章 / 学习提示框 / 生活实例条
- 同一批次生成的多张图，色系必须不同
- **受众是学生，准确性优先于美观**：每张图必须走完 Step 5 提示词自检 + Step 7 成图视觉复核才能交付；发现无法修复的知识性错误必须告知用户，不静默交付
- AI 负责排版和配图，知识点对不对最终以老师和教材为准；交付时提醒用户核对一遍再发给学生
- 章节号默认按人教版标注；用户用其他版本教材时请在输入中说明
- 此 Skill 仅生成静态信息图
